# Material Cloner

選択したGameObjectとその子に含まれるマテリアルを複製し、参照先を差し替えるUnityエディタ拡張です。
ヒエラルキーでの複数オブジェクト選択にも対応しています。

アバターやプレハブのマテリアルを個別に編集したい場合に便利です。

## 使い方

1. ヒエラルキーでGameObject（複数選択可）を選択
2. 右クリック → **マテリアルを複製** → 以下のいずれかを選択
   - **複製+入れ替え**: 通常のマテリアル複製
   - **複製+入れ替え（Material Variantとして作成）**: 親子関係を持つVariantとして作成
   - **バーサーカーモード（初期値で新規作成）**: 同一シェーダーの初期値マテリアルで差し替え

## 対象範囲

選択した各GameObject自身と、その全ての子オブジェクトに含まれる全ての `Renderer` コンポーネント
（`MeshRenderer`、`SkinnedMeshRenderer`、`ParticleSystemRenderer` など）のマテリアルが対象です。

## 機能

- **通常の複製**: 元マテリアルの完全なコピーを作成
- **同一マテリアルの集約**: 対象の複数メッシュが同一マテリアルを参照している場合、複製は1つだけ作成して全メッシュの参照を一括差し替え
- **デフォルトナンバリング**: クローンしたマテリアルには初期状態からナンバリングを付与（例: `default` → `default 1`）し、切り替わりを視覚的に分かりやすく識別可能
- **重複回避**: すでに同名マテリアルが存在する場合は自動で連番を繰り上げ（例: `default 2`, `default 3`）
- **Material Variant**: 元マテリアルを親として継承するVariantを作成（親の変更が自動で反映される）
- **バーサーカーモード**: 元マテリアルと同じシェーダーを使い、プロパティは全て初期値の新規マテリアルを作成して差し替え（確認ダイアログ付き）
- **自動フォルダ作成**: 元マテリアルのフォルダ内に`clone`フォルダを作成して格納
（元が既に`clone`フォルダ内にある場合は同じフォルダに生成）
- **Undo対応**: `Ctrl+Z`で元に戻せます

## 動作環境

- Unity 2022.3.20f1 以降
